配置你的 API

密钥只保存在你浏览器的 localStorage，请求由你的浏览器直发官方 API——本页是静态页，没有后端。 对话槽任选提供商；嵌入槽固定 SiliconFlow bge-m3（检索向量必须与预建索引同模型，这是 RAG 的基本约束）。
SiliconFlow 注册送免费额度，bge-m3 嵌入免费；对话选 SiliconFlow 时只需一个 Key。
隐私说明：站主无法获取你的 Key；每次操作消耗你自己账户的少量额度。
