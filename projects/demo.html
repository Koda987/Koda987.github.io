没有密钥？SiliconFlow 注册即送免费额度，bge-m3 嵌入免费——对话选 SiliconFlow 时只需填一个 Key。
嵌入槽为什么不能换：检索向量必须与预建索引用同一个模型算出，换模型就对不上号（RAG 的基本约束）。
隐私说明：两个 Key 只保存在你浏览器的 localStorage，请求由你的浏览器直发官方 API—— 本站是 GitHub Pages 静态页，没有后端，站主拿不到也存不了你的 Key。每次操作消耗你自己账户的少量额度。
